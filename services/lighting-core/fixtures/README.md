# Lighting Fixtures

Deterministic sample projects and partituras for tests, simulator development and firmware parity checks.

Fixtures should be small, versioned and intentionally named.

Current fixtures:

- `partitura-v2-minimal.json`: valid acceptance fixture for generator, player
  stress tests and firmware parity work.
- `partitura-v2-invalid-output.json`: invalid three-output/dense-index fixture.
- `partitura-v2-invalid-references.json`: missing references and unsupported
  effect fixture.
