# Lighting Fixtures

Deterministic sample projects and partituras for tests, simulator development and firmware parity checks.

Fixtures should be small, versioned and intentionally named.

Current fixtures:

- `partitura-v1-minimal.json`: valid acceptance fixture for generator, simulator and firmware parity work.
- `partitura-v1-invalid-output.json`: invalid logical output fixture.
- `partitura-v1-invalid-references.json`: missing references and unsupported effect fixture.
